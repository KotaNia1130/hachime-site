# 八目 HACHIME｜網站 MVP V0.7

這是八目 HACHIME（跳蛛研造）的網站互動原型。

- 首頁：可拖曳、縮放的筆記桌面；拖曳時不反白文字
- 固定頂部導覽，點擊內容後進入詳細閱讀畫面
- 新手指南、跳蛛圖鑑、飼養常見問題
- A1 飼養盒規格選擇及模擬購物車

## 本地預覽

直接以瀏覽器開啟 `index.html` 即可，無須安裝套件或啟動伺服器。

## GitHub Pages

到儲存庫 Settings → Pages → Build and deployment，設定：
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

儲存後，待 Pages 發布完成，正式網址應為：

https://kotania1130.github.io/hachime-site/

## 注意事項

目前是測試版，未提供正式金流、結帳、資料庫或使用者帳號。商品價格與部分知識內容為規劃與示意，正式營業前須逐項確認。
