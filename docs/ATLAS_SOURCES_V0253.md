# 八目 HACHIME｜圖鑑精簡與公開圖鑑索引 V0.25.3

更新：2026-11-16（台灣時間）。

## 修訂原則

八目公開圖鑑不需要因為想增加物種數量，就收錄只有拉丁學名、而找不到公開中文名稱或可靠玩家／商家稱呼的條目。

- **保留**：可以查到已公開使用的中文名稱（臺灣物種名錄、地方圖鑑、攝影／觀察紀錄、可靠商家原始用例等），或有實際來源的玩家常稱；並清楚註記名稱性質。
- **移出公開圖鑑**：找不到公開中文名稱或可靠玩家用例、或名稱無法對應到具體分類單位的條目。它們可以留在後續研究清單，但不佔圖鑑主目錄。
- **中文名與分類不是一回事**：有中文俗名不代表臺灣正式名錄採用；有拉丁學名也不代表某個不確定中文暱稱可以套用。
- **圖片**：外部網站可公開瀏覽，不代表照片可直接複製到營利網站；圖片仍逐張確認作者及授權。

## 可公開使用來比對的圖鑑

1. **[嘎嘎昆蟲網：蠅虎圖鑑](https://gagaphoto.com/new23/cp04_63.htm)**：台灣常見跳蛛的照片、中文用名和學名，適合找名稱或初步辨識。屬個人資料整理，不能視為最新分類權威；圖片授權需另外確認。
2. **[臺灣蛛式會社](https://spider.tbn.org.tw/)**：台灣蜘蛛觀察紀錄、種類、鑑定歷程及部分照片；也是台灣生物多樣性網絡 TBN 的公民科學資源。
3. **[林業及自然保育署：台灣常見蜘蛛圖鑑](https://www.forest.gov.tw/0010237)**：政府提供的公開 ZIP 下載，下載並解壓後可用舊式 `index.htm` 查看。出版年代較早，使用前核對新分類。
4. **[Jumping spiders of the world](https://jumping-spiders.com/nav_general/start.php)**：大量國際跳蛛照片、圖版及分布資料。網站標註僅供研究／教育非商業用途，絕對不能因此把圖片認作可自由商用。
5. **[World Spider Catalog](https://wsc.nmbe.ch/)**：核對學名、命名者、屬／種層級與歷史組合的分類權威；不是以中文名或入門照片為主的圖鑑。
6. **[TaiCOL 臺灣物種名錄](https://taicol.tw/)** 和 **[TBN 臺灣生物多樣性網絡](https://www.tbn.org.tw/)**：核對臺灣的中文名稱、學名及分布紀錄；注意不同平台不一定同步，部分資料僅為公民觀察標籤。
