# 翻頁修改與驗收

實作分支：`fix/reverse-paper-turn`。

## 現行方案

開啟與返回共用同一組紙面、紙背、陰影及折角動畫，長度 760ms。開啟正放，返回設定 `direction: reverse` 倒放；速度變化與折角路徑完全相同，沒有另外一套返回旋轉。

開啟先掀右下角，再翻整頁。返回沿原路翻回，最後放下同一個紙角。返回時原內頁保留在下層，首頁紙面覆蓋上來；複製內容放在不可互動的 Shadow DOM，保留照片、目錄及捲動位置，不鏡像文字。

快速連點立即更新目的地，保留正在播放的紙面；返回中的首頁快照也會更新成最新目的頁。調整視窗、離開分頁或啟用減少動態效果會清理動畫，不支援動畫時直接切換。

## 驗收

`npm test -- paper-interactions paper-visuals browser-smoke`

- 比對正反向四組 keyframes 完全相同，且在對應時間點，紙面、紙背及折角沿同一路徑返回。
- 比對翻頁第一格與原頁，包含捲動過的文章及圖鑑目錄，避免整頁變淡、文字鏡像或位置跳動。
- 檢查快速連點、最後目的地、減少動態效果、縮放和轉場清理。
- 主要操作測試涵蓋 320–1440px 排版、拖曳、導覽、瀏覽器返回、圖鑑、輪播及購物車。

測試使用雲端 Linux Chromium；手機為模擬視窗。Windows、實機手機的觀感仍需人工確認。先前慢速 CPU 測試曾出現建立快照時的單次停頓，不保證所有裝置固定 60fps。
