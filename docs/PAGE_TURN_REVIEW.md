# 翻頁修改與驗收

實作分支：`fix/bottom-corner-turns`。

## 現行方案

開啟與返回共用同一套紙面、紙背、陰影及折角動畫，長度 760ms。兩邊都從底部掀起小角：開啟從右下，返回從左下。返回水平對調裁切幾何與折線位置，時間維持正放，不再倒播，因此不會從上方開始。

開啟與返回都保留當下頁面作為翻動的紙面，下一頁在底下；複製內容放在不可互動的 Shadow DOM，保留照片、目錄及捲動位置。只改折線左右方向，文字不鏡像、不旋轉。

快速連點立即更新目的地，保留正在播放的紙面；底下頁面會更新成最新目的地。調整視窗、離開分頁或啟用減少動態效果會清理動畫，不支援動畫時直接切換。

## 驗收

`npm test -- paper-interactions paper-visuals browser-smoke`

- 檢查兩個方向在開頭都從底邊的小角掀起；對應時間點的裁切座標只左右對調，垂直位置一致，返回用左下角、開啟用右下角。
- 比對翻頁第一格與原頁，包含捲動過的文章及圖鑑目錄，避免整頁變淡、文字鏡像或位置跳動。
- 檢查快速連點、最後目的地、減少動態效果、縮放和轉場清理。
- 主要操作測試涵蓋 320–1440px 排版、拖曳、導覽、瀏覽器返回、圖鑑、輪播及購物車。

測試使用雲端 Linux Chromium；手機為模擬視窗。Windows、實機手機的觀感仍需人工確認。先前慢速 CPU 測試曾出現建立快照時的單次停頓，不保證所有裝置固定 60fps。
