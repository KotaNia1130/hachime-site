# V0.25｜跳蛛圖鑑名稱與學名核對（2026-11-15）

本次以 **World Spider Catalog（WSC）** 核對分類學名、命名者與物種／屬的層級；台灣條目中文名稱則以 **TaiCOL／台灣生物多樣性網絡（TBN）** 的物種頁核對。玩家、商家暱稱只在有原始用例時使用，不能當作正式分類學中文名。

網站圖鑑入口由 10 個增至 **19 個**，包含「物種」與「屬級整理」入口。**19 個入口不等於 19 種已核對物種**，因為綠翠尚未鑑定、澳洲孔雀蜘蛛及西邁塔是屬／類群資訊。

## 圖片、頁面與測試處理

- 保留原有 3 張已核對來源照片（*Phidippus regius*、*P. audax*、*Hyllus diardi*）。圖片的物種標籤與原始授權不變。
- **新增物種不會借用其他種照片**：在找到可靠照片、逐張確認作者與授權以前顯示「照片待補」。
- 保留 `#atlas/simaetha`、`#atlas/hyllus`、`#atlas/giganteus` 等舊網址。新增物種都有獨立 `#atlas/{id}` 入口。
- 物種資料集中在 `assets/species-data.js`；圖鑑菜單由資料自動生成，無需在 HTML 手動複製。
- 更新 `tests/atlas-catalog.cjs` 的 19 個入口及預期學名。尚須在有 Chromium／Playwright 的環境跑實際瀏覽器測試。

## 重要方法限制

不同平台的「學名有效」和「台灣是否有分布紀錄」不是完全相同的問題。若 TBN 和 WSC 的分布敘述不同，先明示差異而非任選一邊。商業照片、玩家貼文、單一個體拍照及原產地資訊不能自動作為物種的分類證據。中文俗名與臺灣正式中文名也應分開標示。
