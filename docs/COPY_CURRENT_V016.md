餵食與供水

跳蛛突然不吃東西？

脫皮與成長

留意絲巢與近期活動變化，減少干擾。不要任意拆除絲巢，也不要把可能傷害個體的活餌留在箱內。

一直躲在絲巢裡？

跳蛛會在絲巢裡休息，也可能準備脫皮。不要任意拆除絲巢；先觀察近期活動及脫皮紀錄。

準備脫皮時可以餵食嗎？

應減少干擾，避免把可能傷害跳蛛的活餌留在箱內。脫皮後是否恢復餵食，需依個體恢復情況判斷。

跳蛛逃出來怎麼辦？

先限制人與其他寵物進出，關閉房門並仔細檢查附近高處及安靜角落。不要使用殺蟲劑；找到後使用安全容器引導回箱。

若有明顯行走失調、虛弱或外傷，先降低環境干擾，避免自行用藥或強迫餵食，並儘快尋求有無脊椎動物照護經驗的專業協助。

01 / 先記下日常問題

開盒、餵食、清潔與觀察，都會影響飼養盒的使用方式。我們先把這些情境列出來，作為整理設計的起點。

02 / 目前的構想

A1 規劃不同尺寸與 CORE、PLUS、PRO 等級，用來討論基礎結構與功能配置。現在呈現的是設計目標，不是已驗證的性能承諾。

03 / 下一步要驗證的事
箱門、接縫與通風孔的防逃條件。
通風、攀附及結絲空間的配置。
餵食與清潔操作是否方便、能否減少干擾。
