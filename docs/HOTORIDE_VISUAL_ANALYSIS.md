# ほとりで網站觀察：構圖、素材與閱讀方式

觀察日期：2026-11-15。參考網站：https://hotoride.com/ 。此文件保存設計分析，並非 HACHIME 新版規格或已完成的改版。

HACHIME V0.18 的既有意見另存於 [畫面檢視紀錄](HACHIME_V018_VISUAL_REVIEW.md)。本次沒有修改網站程式或部署內容。

## 觀察範圍與限制

使用 Chromium 實際查看桌面 1440×1000、手機尺寸 390×844：首次操作說明、首頁拼貼、目錄、活動指針、森之宮介紹、設施概要、五篇文章入口、外部連結區，以及 `/story-01` 文章內頁。操作目錄跳轉、縮放、同一分頁重新整理，另補看文章捲動後的正文。

瀏覽器對外連線透過保留正常 TLS 驗證的 curl 取得公開資產後呈現；不以本次載入時間評斷實站效能。非 GET 請求未執行。這是視覺及部分操作觀察，不是完整無障礙、效能或手機實機驗收。首次與文章截圖曾過早捕捉到空白紙面，文章已等待載入後重拍；不把這些暫態截圖當作實站缺陷。

## 1. 首先要修正的理解：它也有規律的排列

五張「仮説と視点」文章入口使用相同的藍色資料夾、編號、照片組與閱讀入口，整區接近上二下三的規律排列。設施資訊也採清楚的文字對齊。

它把規律用在需要辨識、比較和閱讀的地方。周圍的品牌照片群、理念圖解、地方介紹和聯絡標籤則採不同構圖。整體變化來自區域之間的差異，並不需要讓每張紙都排亂。

## 2. 一張可以向四周探索的大紙面

首頁主畫布為 3300×3300，程式結構有四個 1650×1650 的區域，存在明確的底層安排。觀看時，照片和文字的邊緣會超出視窗，暗示四周還有內容；目錄可以直接把視角移到對應區域。

這種構圖允許相鄰主題在視野中交會，與一直往下堆入口的長頁有不同感受。但視窗裁切需要導覽協助，不能把看不到內容本身當作設計優點。

## 3. 品牌開場由一群有關係的照片組成

中心的大字標周圍排列活動、工作坊、室內、街景、人物和手部操作照片。照片的遠近、內容、大小與方向都不同，能讓人理解這個場所實際發生什麼事。

相紙彼此有遮擋，膠帶與照片靠在一起；字標附近留出呼吸空間，照片群則相對密集。這種局部的疏密讓畫面有重點。把同一張照片裁成幾種形狀，無法得到相同的資訊量。

對 HACHIME 的啟示：照片可分擔個體特徵、環境、行為和觀察過程等不同內容。只有物種正面照時，不宜用重複照片假裝有很多紀錄；也不能拿他人照片當成八目的實拍成果。

## 4. 紙張與插畫有一致的製作感

可見紙纖維、折痕、相紙白邊、不齊的膠帶邊緣、手寫圈線，以及帶有印刷顆粒感的字標。照片與相紙看起來是同一個貼上去的物件；迴紋針和膠帶有明確的附著位置。

這些細節讓物件彼此協調。單獨添加 CSS 陰影、紙框角度或不同風格的插圖，未必能形成同樣的效果。其具體製作流程無法僅憑成品確認，不推定全部素材都是真實掃描或手繪。

HACHIME 應先統整照片邊框、紙張質感和註記線條，再判斷哪些素材適合保留。正文清晰度仍是前提，不應為了擬真而重新旋轉整段文字。

## 5. 顏色有份量差異

背景是偏灰白的紙面；深色文字提供辨識度。藍色用在大標、資料夾與大面積不規則色塊，黃色用在便條和重點標示，橘紅色用於少量手寫註記，綠色線條出現在部分圖文邊界。照片另外帶入生活場景的色彩。

其中活動指針旁的大藍色塊，具有足以平衡周圍紙面的面積；點綴不只是一條小邊線。不同顏色同時有主次與用途，整頁沒有把所有區塊都處理成相近的淡色。

HACHIME 可以保留品牌綠，讓一兩個主要區域承擔較深的綠色面積，旁註再用少量暖色。具體色值與面積應透過版面草圖確認，本文件不先定稿。

## 6. 圖解和手寫註記與內容相連

網站介紹森之宮的場所與社群活動；「共生」與環境邊界是內容的一部分。因此森林／水域交界的 ecotone 圖解有文字說明，也與社群之間的連結概念相呼應。地方地圖則服務地點和區域資訊。

文章內頁可看到黃色「假說」便條用箭頭連向下方的「觀點」正文，線條直接表達閱讀關係。這比沒有明確對象的箭頭更有理由存在。

對生態筆記而言，註記適合指出照片裡具體可辨識的眼睛、足部、絲巢等內容；圖解適合說明已核對的觀察或照顧知識。尚無資料的繁殖紀錄應維持真實空狀態，縮小其份量，不能填入虛構日期或成果。

## 7. 首頁探索與長文閱讀分工清楚

首頁可使用大字、直排日文、短註記和照片拼貼來建立視覺變化。進入 `/story-01` 後，是藍色資料夾包覆的單篇文章：大標、重疊照片、黃色摘要便條，再進入白紙上的水平正文。

內文有一致的行寬、段距、標題、配圖和圖注，可以正常垂直捲動。資料夾側邊保留關閉標籤，視覺上與首頁的文章入口相接。

HACHIME 的圖鑑、飼養說明和選購內容，可以沿用這種分工。首頁允許圖文交錯；查學名、照顧資訊、規格和價格時，優先讓讀者容易掃讀。日文直排的比例不必直接套用到繁體中文長文。

## 8. 操作說明簡短，目錄平常收起

首次提示使用實際畫布縮圖、手勢符號、簡短操作文字及一個開始按鈕。它先說明陌生的探索方式，讓使用者知道進去之後如何移動。

左側「もくじ」標籤開啟資料夾式目錄，六個入口對應內容區。桌面的小地圖顯示所在範圍，縮放按鈕協助探索。目錄平時收起，不會一直占用大塊閱讀空間。

實測同一分頁重新整理後，操作提示與 loading 均未再次顯示；公開程式中的操作提示使用 sessionStorage。這不能解讀成一位訪客永久只看一次。loading 與提示應分開理解：前者回應準備內容的狀態，後者教操作。本次未量測真實 loading 時長，也不以較早的空白截圖推定動畫表現。

## 9. 手機保留探索特色，也有閱讀代價

390px 寬的首頁仍呈現大畫布的一部分，字標與照片維持存在感；目錄則能完整展示六個入口。並未把所有素材重新排成一條普通長頁。

但在活動指針區，大標會超出右側視窗；文章入口區也只能看到部分構圖。使用者需要移動或縮放來理解全貌。這適合有探索意願的人，對急著查照顧問題的新手則有成本。

因此 HACHIME 可以借用構圖與收納式導覽，同時保留直接進新手指南、搜尋及詳細閱讀的入口。手機首頁是否沿用完整自由畫布，仍應獨立比較和測試，不能單憑參考站有做就決定採用。

## 後續設計應優先處理的事情

1. 先用一組內容做完整構圖：一張有意義的主照片、相關細節、具體註解，以及可進入閱讀的入口。
2. 拉開區域之間的差異。圖鑑適合照片與索引；繁殖日記適合帶日期的觀察串；用品適合規格資料袋，不必全部用相同便條模板。
3. 讓照片、線條、紙張與字體的製作感一致，再增加裝飾。
4. 建立明確的深淺色份量與局部疏密，減少沒有內容關係的空白。
5. 保持詳細頁文字清晰，收斂常駐工具，單獨處理手機的快速查閱需求。

以上為從參考站推導的方向，尚未變成新版規格，也未修改 HACHIME。
