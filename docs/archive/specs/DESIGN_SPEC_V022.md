# HACHIME V0.22｜連續內文與章節目錄

> 目錄位置與動畫已由 [V0.23](DESIGN_SPEC_V023.md) 更新：左側章節、快速捲動、軟紙轉場；連續內文維持。

日期：2026-11-15。

## 需求與配置

首頁保持既有完整筆記桌面。點進便條才開啟內頁；首頁沒有目錄，也不保留側欄空白。去除摺痕、紙型、照片與文字風格沿用。

新手指南七章一次呈現，可直接往下閱讀。移除 01–07 按鈕、編號副標、上一步／下一步和逐章切換；保留各章閱讀勾選、瀏覽器本機進度及重設。飼養筆記五主題也連續呈現，FAQ 放在後方，仍可分類、搜尋和展開問題。

目錄放在詳細頁右側，只列目前文章的章節，沒有首頁或其他分類的入口。點擊定位到標題，不隱藏其他章節、不播放換頁效果。手動捲動更新章節標記。960px 以下收合為工具列「章節」按鈕，點擊選項後關閉；支援 Escape、鍵盤及移動焦點到目標標題。

圖鑑保留物種選擇，選購保留活體／用品分類、輪播與規格；這些是內容選擇器。它們的側邊目錄同樣只定位目前內容標題。頂部導覽繼續負責全站分類。

## 路由與返回

- `#beginner/1` 至 `#beginner/7`、`#knowledge/environment` 等舊連結仍有效，現在定位長文中的章節。
- 其他章節連結使用目前路由加 `?section=標題ID`，支援複製連結、重整與瀏覽器前後頁；無效標題回本篇開頭。
- 返回筆記桌面保留原平移與縮放位置。拖曳與縮放不導覽，只有跨分類開啟內容才顯示紙面轉場；減少動態設定略過。

## 驗證與限制

沿用 README 的四套 Playwright 測試。重點包含首頁不出現目錄且使用全寬、長文所有章節同時存在、章節定位位置及焦點、捲動標記、手機收合、歷史與重整、舊閱讀進度、跨內容連結、FAQ、圖鑑、輪播與購物車。320–1440px 核對無水平溢出，桌面及手機截圖檢查。

Windows ClearType 與實際手機仍待人工確認。內容、正式照片、繁殖紀錄、社群連結及商品資料延續原本待補狀態。
