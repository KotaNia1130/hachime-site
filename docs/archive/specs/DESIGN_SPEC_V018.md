# HACHIME V0.18｜生態觀察筆記

本版回應「太單調、太整齊」：保留筆記桌面與六個分類，拆開一致的色卡版型。各區按內容用途使用不同紙張、照片與標籤。

## 版面

- 桌面 1500×3410，手機 420×6990，沿用 CSS zoom 與拖曳邊界計算。
- 開場：大幅佛跳照片搭配小型 A1 概念圖、同照片的圓形局部裁切、來源標記、手寫旁註。手機把局部特寫移到品牌旁，主照片向下接續。
- 新手起步：窄版撕邊橫線紙、清單方框，整張仍是閱讀入口，方框不是可勾選表單。
- 圖鑑：撤除大色卡背景，三張照片使用不同尺寸、位置與紙底角度；名稱、學名與來源連結保留。
- 飼養筆記：有側邊紅線的淡黃橫線紙，列出環境、餵食和觀察項目。
- 繁殖日記：暖白紀錄表、綠色側條、迴紋針、日期／個體／階段空白線與「準備中」標記；空欄只是預覽，不製造實際繁殖資料。
- 活體與用品：牛皮資料袋樣式，兩個分類連結保留。
- 開發札記：方格草稿紙與現有概念圖；更新區直接排在紙面，關於八目使用窄版標籤紙。
- 手機便條寬度不同，照片錯落，使用位置索引與頂部選單跳轉。核心正文維持水平，裝飾與紙底可傾斜。

## 素材與文字

- 使用原三張授權跳蛛照片；新加 Wellcome Collection 的蕨類歷史圖版，僅作筆記裝飾。原圖版的植物名稱帶不確定性，不當成跳蛛棲地或八目採集紀錄。
- 圓形特寫是佛跳同一張照片的 CSS 局部裁切，不新增物種或個體宣稱。
- 手寫旁註使用本地 LXGW WenKai TC 文字子集，授權 SIL OFL 1.1，避免外部字型失敗時失去旁註風格。正文與主導覽仍沿用原字體配置。
- 紙面噪點、撕邊、裝訂孔、迴紋針與細線箭頭使用 CSS／SVG，裝飾線不攔截點擊。
- 日期標示為「素材整理 / 2026.11」，不是虛構觀察日期。原標語提案仍待確認，未整批套用新文案。
- 來源、作者、授權、下載時間及 SHA-256 見 `ASSET_CREDITS.md`、`assets/field-materials.json`。

## 互動與驗證

路由、導覽、圖鑑、輪播、購物車、分頁提示與進度儲存維持；標本風格的名稱標籤可連到既有老虎狗圖鑑。

- `tests/browser-smoke.cjs`：七步指南、圖鑑、FAQ、輪播、用品規格／價格／購物車、拖曳縮放與 320–1440px 詳細頁排版。
- `tests/brand-experience.cjs`：分頁提示、鍵盤與深層連結、位置索引、繁殖頁、照片後備圖、減少動態與儲存失效。
- `tests/field-layout.cjs`：320／390／1440px 下，以實際滾輪平移後點擊／觸控六個入口；照片來源連結可命中，名稱標籤可跳轉，本地圖片與字型成功載入，觸控拖曳不誤開內容。
- 桌面與手機截圖檢查照片、署名及按鈕的間距。另以 deviceScaleFactor 1.25 檢查原有互動；Windows ClearType 仍需實機確認。
- 發布後核對 GitHub Pages 的建置 commit 及線上 HTML、CSS、植物圖版、字型檔案內容。
