# 八目 HACHIME｜V0.14 規格

沿用 V0.13 的內容、淡暖色系與素材授權規範。本版新增第六張便條及 `#live` 詳細頁；V0.13 的「五張便條」描述為歷史規格。

## LOGO 與文字

- 現用 `hachime-symbol-v2.svg` 最左眼的高光移至右上，每眼一點。其他圖形、配色與構圖不變。
- 首頁以 CSS `zoom` 縮放版面，避免 transform scale 的文字點陣層放大；不固定 will-change 合成層。
- 便條／操作提示的文字層不旋轉；紙張偽元素維持微斜、陰影與色彩。照片可旋轉，圖注維持水平。詳細內文維持可選取。
- 拖曳、縮放中心、邊界限制與點擊判斷仍以視窗像素運算。紙張裝飾不攔截滑鼠或觸控。
- Chromium 為本次驗證目標。Linux 截圖不能代替 Windows ClearType／125%、150%、200% 顯示縮放的人工檢查。

## 蜘蛛活體

- 第六張便條標示「蜘蛛活體 / LIVE SPIDERS」，具頂部導覽、便條點擊與鍵盤開啟入口。
- 佛跳、老虎狗、獅子狗各有名稱、一句簡介及暫用示意插圖；獅子狗學名待核對，不自行指定物種。
- 三項全部標示「示意 / 規劃中」，不宣稱庫存、在養個體或正式販售。
- 5.6 秒換圖；hover、focus、document.hidden、詳細頁或 prefers-reduced-motion 時停止自動換圖。手動按鈕仍可用，Enter／空白不誤開詳細頁。
- 詳細頁列物種名稱、待核對學名、簡介、狀態及未來欄位：個體編號、性別、齡期、來源、進食／脫皮紀錄、實拍與更新日期。
- 活體不加入測試購物車；原 A1 模擬購物車保留。
- 桌面置於飼養盒便條下方；手機接續關於八目，單欄排列。頂部標籤可水平捲動。

## 驗收

`tests/browser-smoke.cjs` 使用 Chromium，檢查拖曳、縮放、導覽、上一頁、圖鑑、FAQ、新手章節、尺寸、價格表、購物車、既有與新增輪播、鍵盤操作、140% 無文字層 transform、手機溢出及未捕捉的 JavaScript 例外。以刻意阻擋遠端資源驗證離線替代行為。

保留人工確認：Windows 實機字型清晰度、正式照片與學名、個體紀錄及未來販售政策。外部照片／字型的實際可用性需另行確認。
