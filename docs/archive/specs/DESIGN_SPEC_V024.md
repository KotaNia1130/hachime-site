## 翻頁效能

原本每次翻頁都深複製全畫布／所有內頁，再於 Shadow DOM 建立一份完整 CSS。首次樣式解析、重複 DOM 及材質陰影重繪會集中在點擊瞬間。

現在預先在閒置時解析共用 constructable stylesheet，每次轉場直接採用；只擷取首頁視窗附近的絕對定位區塊，或目前正在閱讀的一篇內容。轉場副本移除紙紋噪點、巢狀陰影與濾鏡，只保留翻頁本身的陰影；原頁面的紙感不變。舊動畫清理、中斷、減少動態及套件失敗後備保持。

[效能量測](../../PAGE_TURN_PERFORMANCE_V024.md) 記錄同環境前後數據，不能等同 Windows 或手機實機流暢度。

## 驗證

原有五套 Playwright 測試，加上 `tests/atlas-catalog.cjs`：10 個入口、桌面左側及手機收合、暱稱／學名、未定名／屬級資料、照片一致、舊網址／歷史、普通小字連結與無 JS 例外。涵蓋 320–1440px，截圖核對桌面與手機。

待補：綠翠及西邁塔的可核對名稱來源；新增條目的正式授權照片；實際 Windows／手機的動畫手感。原有繁殖紀錄、社群網址與商品資料仍待補。
