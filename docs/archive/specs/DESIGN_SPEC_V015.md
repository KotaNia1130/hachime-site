# HACHIME V0.15｜新手優先的筆記網站架構

本版落實 `SITE_PLAN_V015.md` 的資訊架構，內容先採簡短 MVP；沿用 V0.14 的標誌、紙張風格、文字層分離及 CSS zoom。

## 已完成

1. 五個首頁入口：新手起步、跳蛛圖鑑、飼養筆記、活體與用品、關於八目。桌面首屏呈現品牌與新手便條，手機品牌區有直接開始按鈕。首頁仍可拖曳、縮放與全覽。
2. 新手七步：飼養責任、物種差異、環境預算、接回前確認、第一週、日常與脫皮、查問題。每步有短篇介紹、三個重點、一項閱讀勾選、延伸連結與前後步驟。
3. 閱讀進度存在 `localStorage` 的 `hachime-guide-v015`，可重設。資料不可存取時仍能閱讀；進度不代表實際飼養能力認證。
4. 圖鑑首頁用三張固定原創示意圖，物種詳情仍保留來源照片與載入失敗替代圖。以固定物種 ID 提供子路由，已知物種的活體規劃卡可回到對應圖鑑。
5. 飼養筆記含環境準備、餵食供水、脫皮成長、日常觀察、異常求助五個短主題；保留原本八題 FAQ、搜尋及分類。主題與新手步驟互相連結。
6. 選購包含總覽、活體、用品三個頁內入口。活體輪播移至此處，具下一項、暫停／恢復；hover、focus、隱藏分頁、隱藏面板與減少動態時不自動換圖。
7. A1 尺寸／等級、規劃價目表與模擬購物車維持可用。沒有新建實際付款、會員或活體交易功能。
8. 關於頁補上資料／示意原則與研發入口，不虛構聯絡資料。

## 路由與內容界線

- 新主入口為 `#shop`；子頁 `#shop/live`、`#shop/equipment`。舊 `#live`、`#lab` 仍可直接載入，不要求使用者改書籤。
- `#beginner/1`～`#beginner/7`、`#atlas/regius|audax|hyllus` 與 `#knowledge/environment|feeding|molting|observation|help` 支援直接載入、重新整理、瀏覽器前後頁。斜線後的 `|` 表示選項，不是網址的一部分。
- 未知分類回到該主頁，未知主頁或無效編碼回到首頁；不把網址文字直接插入 HTML。
- 頂部標籤標示主區域，頁內標籤標示實際子頁。動態產生的延伸連結使用共用路由事件。
- 三個活體項目皆為示意／規劃中。獅子狗學名未確認，連向物種確認指南；不建立虛構的確定物種資料。
- 本版沒有引入新第三方素材；沿用 `ASSET_CREDITS.md` 的授權與示意標示。

## 檢查方式

以 README 的 Python 靜態伺服器及 `node tests/browser-smoke.cjs` 重跑。Playwright／Chromium 由開發環境提供，不是網站運行依賴。

測試涵蓋七步閱讀／保存／重設、跨區延伸連結與瀏覽器上一頁、三種圖鑑與替代圖片、五個筆記主題與 FAQ、選購分類／舊網址、輪播暫停條件、A1 尺寸等級／價目表／購物車、首頁拖曳縮放、錯誤網址，以及 320、390、600、768、1024、1440px 排版溢出。

測試刻意阻擋外部請求以驗證離線替代顯示；不等於外部照片與字型連線正常。`DEVICE_SCALE_FACTOR=1.25` 可補測像素密度；Windows ClearType 仍需實機確認。測試截圖輸出至 `/tmp/hachime-v015-*.png`。

## 後續擴充

- 逐步補充可靠資料來源、物種知識、照顧專題與審閱日期。
- 真實個體的學名、來源、齡期、性別、照片及紀錄，確認後才顯示在養或可提供狀態。
- 正式產品規格、交接／配送與售後政策、聯絡方式及交易功能另行規劃。
- 本版不新增未核實的通用溫濕度、餵食頻率或適養分級。
