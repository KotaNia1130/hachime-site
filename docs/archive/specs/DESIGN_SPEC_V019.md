# HACHIME V0.19｜依內容組成的觀察筆記

日期：2026-11-15。依據 [V0.18 畫面檢視](../../HACHIME_V018_VISUAL_REVIEW.md) 與 [ほとりで分析](../../HOTORIDE_VISUAL_ANALYSIS.md)，本版把照片、短註解與閱讀入口組成相關內容群組；資料頁繼續採水平正文。

## 需求與設計對照

| 需求 | 本版實作 |
|---|---|
| 保留筆記本設計，減少一致卡片的感覺 | 品牌字標與照片群、新手黃紙清單、圖鑑散貼照片、深綠飼養索引、繁殖窄便條、A1 方格草稿、用品牛皮資料袋、簡短更新列表各有構圖 |
| 新手有完整流程 | 開場提供直接開始按鈕；桌面初始視野可見新手清單；七步指南、進度勾選與相關內容連結保留 |
| 圖鑑與活體分工 | 圖鑑比較物種、玩家泛稱和學名；活體及用品共用選購入口，個體狀態、輪播與測試購物車保留 |
| 首頁照片更有用途 | 佛跳主照片搭配正面眼睛註記及物種連結；大膽跳蛛、老虎狗照片用於圖鑑比較，各張在首頁只出現一次 |
| 繁殖日記 | 保留獨立入口與欄位頁；縮小空白區域，清楚標示目前尚無公開紀錄 |
| 開發札記 | 概念圖旁列出通風防逃、開盒餵食、清潔操作的待驗證問題；不宣稱完成打樣 |
| 顏色偏淡 | 品牌綠用於大字、飼養便條與主要操作；黃紙標示新手起步，橘紅少量用於觀察註記 |
| 正文清晰 | 相片與相紙一起傾斜，圖注、標題、正文不旋轉；保留 CSS zoom，不對整張畫布做 transform scale |
| 導覽與引導 | 頂部標籤保留；右下位置索引改為原生 details 收合目錄，支援鍵盤、Escape、點擊外部關閉，選擇後焦點移到內容；首次引導仍依分頁 sessionStorage，問號可重開 |
| 手機版 | 保留單向探索與錯落照片；縮短內容並收合索引，縮放工具與目錄並列，不再上下疊兩組工具 |
| 社群 | Facebook、LINE、Instagram 窗口保留，尚無帳號時停用並標為待設定 |

## 首頁文字

- 品牌：**先看看牠，再認識牠。**
- 介紹：這裡整理跳蛛的物種資料、照顧方法，也記下飼養盒從想法到製作的過程。
- 新手：**想養一隻跳蛛？**／先把這幾件事想清楚。
- 圖鑑：**牠叫什麼名字？**／玩家怎麼叫、學名怎麼寫，放在一起看。
- 飼養：**今天，牠怎麼樣？**／飼養筆記，從每天會遇到的事整理。
- 繁殖：配對、卵囊、孵化、幼蛛成長。有實際紀錄後，會連同照片和日期整理。
- 開發：**一只飼養盒，要想哪些事？**／先把問題列下來，再逐項驗證。
- 選購：個體資料和用品規格，都收在這裡。
- 頁尾：有新的觀察，再添一頁。

V0.17 文案提案保留為歷史討論，本版以上述實際文字為準。沒有改寫整個知識庫。

## 版面與素材

- 桌面畫布 1680×2600；手機 420×4770，比 V0.18 的 6990px 縮短約 32%。手機仍可透過頂部標籤直接進入詳細閱讀，不必一路拖到入口。
- 桌面全覽按照實際可用寬高計算，移除 32% 的下限，避免筆電高度不足時裁切。全覽用於定位；詳細閱讀透過便條、目錄或標籤。
- `assets/notebook-v019.css` 取代 V0.18 樣式引用；V0.16／V0.17 的共用詳細頁及元件樣式保留。舊版 CSS 檔保留供歷史追蹤。
- 沿用已核對授權的三張照片，未取得或複製參考站素材。首頁移除重複照片、植物圖版、沒有明確對象的裝飾圖與空表格。
- 佛跳前方大眼的註記只描述照片可見內容，不用這張照片推定在養個體資料。
- 更新日期是網站內容整理日期，不是觀察或繁殖日期。

## 驗證

以 `BASE_URL=http://127.0.0.1:8001/` 執行：

- `node tests/browser-smoke.cjs`：七步指南、進度保存／重設、瀏覽器上一頁、物種切換、FAQ、輪播暫停條件、商品選項／價目表、購物車、拖曳縮放與 320–1440px 排版。
- `node tests/brand-experience.cjs`：首次及回訪引導、新分頁提示、問號重開、深層網址、目錄定位、繁殖頁、減少動態、儲存不可用、圖片後備圖、無 JS 時仍有首頁。
- `node tests/field-layout.cjs`：320／390／1440px 實際觸控與滑鼠操作六個便條，圖鑑照片連結、來源連結可點、本地照片與字型載入、觸控拖曳不誤開。
- `node tests/notebook-composition.cjs`：320×740、390×844、600×900、768×900、1366×768、1440×1000；目錄鍵盤開關／Escape／焦點、點擊外部關閉、各區定位、圖注不碰頁腳、札記連結不超出紙面、手機工具不重疊、全覽完整、正文不旋轉，以及照片／飼養主題直接連結。
- 桌面、全覽、手機首頁及各主要區域截圖人工檢視；過程中修正圖鑑圖注和頁腳間距、札記紙面高度及註記箭頭。

本機瀏覽器測試阻擋外部請求以驗證本地素材與後備字體；不代表 Windows ClearType、真實手機或外部連線效能驗收。上述環境仍可補做人工檢查。
