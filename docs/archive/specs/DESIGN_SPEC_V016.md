# HACHIME V0.16｜品牌拼貼與觀察札記

使用者核准先找素材、直接修改；完成驗證後合併推送 main。

## 內容與視覺

- 保留 V0.15 五入口及所有原有詳細頁，新加 `#development` 開發札記路由，舊網址相容性保留。
- 品牌開場採暖白方格紙、水平文案、照片卡底層微斜與原創概念圖。OpenMoji 幼苗及放大鏡為輔助裝飾，來源及授權可追溯。
- A1 首篇札記只說明日常問題、設計構想及待驗證事項，不宣稱完成打樣或安全驗證。
- 最近更新為真實已完成的 V0.15 三項內容；日期 2026-11-15 以台北日期記錄該次網站架構更新，不自動刷新日期。
- 位置索引只移動首頁視角，不新增分類。手機重新排版，紙張與文字延續 CSS zoom、不把文字跟隨紙張旋轉。
- 原版占位名言改為閱讀／觀察導引短句。

## 進場與操作說明

- `assets/welcome.js` 採漸進增強；HTML 預設可讀，沒有 JavaScript 時不產生遮罩。
- 只在首頁且本工作階段尚未播放時加入約 0.7 秒品牌動畫。可略過，動畫層不攔截底下內容操作，1.3 秒退出保護與外部素材完全獨立。
- 這是品牌進場，不是下載百分比；不以外部字型或圖片完成作為進站條件。
- 減少動態偏好直接略過進場；深層連結直接開啟內容。
- 首次操作說明使用原生 dialog，有標題、關閉、開始指南及自由探索按鈕，支援 Escape／焦點返回。問號可重新開啟；現有重複提示收起。
- `sessionStorage` 的 `hachime-entry-seen-v1` 記錄進場，`localStorage` 的 `hachime-welcome-seen-v1` 記錄說明。儲存不可用仍可閱讀與關閉。

## 驗證與限制

兩套測試分別驗證原有功能及新版品牌體驗，涵蓋 320–1440px、位置索引、札記／更新連結、首次與回訪、說明關閉／重開／進指南、深層連結、減少動態、儲存不可用、慢速／失敗圖片，以及停用 JS 仍顯示首頁。

分享圖檢查實際 1200×630 產出；本地素材不依賴外部連線。Windows ClearType 與第三方社群分享快取需後續實機確認；照片與 A1 實物資料尚待補充。GitHub Pages 部署狀態與線上檔案在推送後另外核對。
