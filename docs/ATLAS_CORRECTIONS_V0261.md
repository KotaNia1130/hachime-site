## 保留待核對的內容

- 藍翠蛛命名年沿用 Simon, 1889（與 GBIF／ITIS 相符）；TaiCOL API 作 1899 的差異尚待原始文獻核對，沒有直接覆寫。
- 老虎狗／H. diardi、獅子狗／H. giganteus 維持原始用例的對照；巨蠅象仍為暫用中文名。
- 西邁塔仍為 Simaetha sp.，孔雀蜘蛛仍為 Maratus spp.，不當成兩個已確認的單一種。
- WSC 最新分布、來源連結整理及新增照片另行處理。
