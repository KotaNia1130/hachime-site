# V0.26.2：公開網站文案

網站面向一般訪客。介紹物種、說明如何照顧、提供導覽；查證過程與實作規劃留在儲存庫文件。

## 呈現原則

- 直接寫目前已有的內容。沒有短介紹就省略，不用「整理中」「之後補充」填滿版面。
- 大標保留熟悉的名稱，下面列學名；其他中文名有差異才另列。移除每筆「名錄中文名」「非玩家暱稱」「已核對學名」等編輯標籤。
- 西邁塔仍為 Simaetha sp.（尚未定種）；孔雀蜘蛛仍為 Maratus spp. 類群；巨蠅象保留「暫稱」。精簡文字不代表消除分類上的不確定性。
- 分布沿用已查得的範圍。臺灣名錄記錄簡寫為「臺灣有紀錄」或包含臺灣的分布，不新增全球原生／引入判定。
- 參考資料使用原生 details/summary，預設收合，可用滑鼠或鍵盤展開。現有來源名稱及網址不變。
- 圖片署名、授權、示意圖標示、商品尚未販售及購物車不會成立訂單等資訊保留在相關位置。

## 改動範圍

圖鑑 31 筆的短介紹、名稱排版及分布文字；首頁便條與最近更新；活體卡移除未來資料欄位；繁殖日記保留簡單空狀態；開發札記保留設計構想和接下來要試的事項；關於頁、頁腳與瀏覽器標題移除版本／內部工作描述。新手指南與飼養筆記移除編輯進度說明，保留照護內容與求助資訊。

舊欄位、來源差異及名稱分類保存在 [V0.26.1 編輯紀錄](ATLAS_EDITORIAL_NOTES_V0261.json)。原有照片來源詳見 [素材授權](../ASSET_CREDITS.md)。未改動導覽、拖曳、翻頁、輪播或購物車事件處理。
